📖 How the Pattern System Works

🔬 What it analyzes

Reads 5+ years of NSE daily OHLCV data for ~2000 stocks from your GitHub data repo. Tests 30 signal types across volume, candle, breakout, trend, and combination categories. All prices are actual NSE closing prices — no estimated data.

📐 Win Rate Calculation

For each signal occurrence, looks at the closing price 5, 10, and 20 trading days later. If close is higher → WIN. Win Rate = wins / total occurrences × 100. Measured separately at each time window.

🏆 Grade System

Grade A = 100% win rate with 10+ occurrences. Strongest possible. Grade B = 100% win rate with 5-9 occurrences (validate manually). Grade C = 90%+ win rate with 20+ occurrences. Grade D = 80%+ with 30+ occurrences.

🌐 Cross-Year Filter

A pattern must appear in at least 2 different calendar years to be included. This eliminates COVID-era artifacts and other one-time events. If a pattern only worked in 2020 — it's excluded.

💰 Buy Zone Calculation

Buy zone is ±0.3–0.5 × ATR(14) around the signal close price. Stop loss = 1.5 × ATR below close. Target 1 = 1.5 × ATR above. Target 2 = historical average 20-day return above close. ATR adapts to each stock's volatility.

⚙️ Update Schedule

Pattern discovery runs nightly at 11:45 PM IST after the NSE data fetch. Today's alerts reflect the latest NSE closing prices. GitHub Actions runs the engine automatically — just open this page fresh each morning for today's signals.

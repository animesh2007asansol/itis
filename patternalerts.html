📖 System Rules & Signal Reference

Hard Thresholds (all must pass)

✓ Win rate: 100% at 5d, 10d, AND 20d
✓ Avg return 5d: ≥ +3%
✓ Avg return 10d: ≥ +7%
✓ Avg return 20d: ≥ +10%
✓ Volume on signal day: ≥ 1,00,000 shares
✓ Appears in: 2+ different years
✓ Max gap between years: ≤ 2 years

Grade System

A+ Pattern fired in 4+ years, 8+ occurrences
A Pattern fired in 3+ years, 5+ occurrences
B Pattern fired in 2 years, 3+ occurrences
C 2 years, fewer occurrences
More years = more reliable = higher score

Alert Window

Shows signals from the last 20 trading days (not just today). For each, shows: how many days ago it fired, current price vs signal price, and whether the stock is still in the buy zone (below historical average return), running (between min and avg return), or has hit the sell zone. Filter by Today / Last 7 days / All 20 days.

Repeating Score

Score = n_years × avg_ret_20d × log(occ+1)
A pattern firing in 4 years with 15% avg return scores much higher than one firing in 2 years with 15%. The Most Reliable tab ranks purely by this across 4+ year patterns.

📖 Field & Column Guide

📈 Return Columns
Avg Ret%Average return across ALL historical trades. Entry = next-day open after signal. Exit = close after Hold Days.
Min Ret%The LOWEST return ever in history — still positive (100% rule). This is your guaranteed worst-case profit floor.
Max Ret%Highest single-trade return ever seen. Shows the ceiling.
Max Gain%Average highest intraday close during hold period vs entry. If you sell at the intraday peak, this is what you could get.
Max DD%Worst intraday dip below entry during hold window. Shows max pain before recovery. Even if negative here, the final exit return is always positive.
OOS Ret%Average return on the unseen out-of-sample half. The most important verification number.
Hold DaysTrading days to hold. 5 = short-term (~1 week). 20 = medium-term (~1 month). System picks whichever gives the better result.
📡 Signal Context Columns (historical range when signal fires)
RSI at SignalRSI range when this signal historically triggered. If today's RSI is inside this range, the signal is in its confirmed zone. Below 30 = oversold. Above 70 = overbought.
Vol Ratio at SignalVolume ÷ 20-day average when signal fired. 2x = double normal volume. Shows how much institutional activity was present when the pattern triggered.
5d Before%The 5-day return BEFORE the signal. Negative = stock was falling before reversal. Positive = continuation signal. Tells you what trend preceded the pattern.
20d Before%20-day return before signal. Shows macro context — was it a downtrend reversal or uptrend continuation?
RSI now / Vol Ratio nowCurrent values. Compare with the historical range — if they match the range, today's signal is in the same zone as all past wins.
1W% / 1M%Actual return in last 1 week and 1 month as of today. Compare with ctx_ret5 and ctx_ret20 range to see if context matches historical triggers.
🏅 Other Fields
LT Score (0-100)Long-term suitability score. Above EMA50 (+15), 60d positive (+10-20), A+ strategies (+up to 20), best avg return (+up to 15).
SharpeRisk-adjusted return. Higher = better return per unit of variability. Above 1.0 is good, above 2.0 is excellent.
n_strategiesNumber of independent strategies that passed 100% win rate on this stock. More = higher confidence the stock has multiple reliable entry patterns.
Turnover CrAverage daily trading value in crores. Proxy for market cap. Rs 5Cr+ daily = typically 500Cr+ market cap.
Signal History tabEvery historical occurrence of every qualifying signal, with: signal date, entry date, exit date, actual return, 3d/10d intermediate returns, and the exact RSI/vol/trend conditions when it fired.
